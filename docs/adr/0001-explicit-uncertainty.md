# ADR-0001 — Явная модель неопределённости у каждого числа

- Статус: Accepted
- Дата: 2026-10-28
- Этап: 02 (решение из `docs/03`)

## Контекст

Пользователи склонны читать квантили модели как реальную вероятность исхода (PRD PR-01). Без явной семантики интервал на графике вводит в заблуждение.

## Решение

Каждое число в contracts несёт `uncertainty_type`: `none`, `predictive_quantiles`, `conditional_model_quantiles` или `calibrated_interval`. Значение `calibrated_interval` разрешено только после эмпирической проверки покрытия (Stage 17). Observed-значения всегда имеют `none`.

## Как проверяется

Валидатор `MetricValue` отклоняет observed-значение с неопределённостью прогноза. Фикстуры — `packages/contracts/fixtures/`.

## Последствия

UI (Stage 03, 06) обязан показывать подпись типа неопределённости рядом с каждой полосой. Новые типы неопределённости требуют MINOR-версии contracts.

## Отвергнутые альтернативы

Свободный текст в подписи графика: нельзя проверить автоматически.
