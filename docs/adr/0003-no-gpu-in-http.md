# ADR-0003 — Никаких обучений и тяжёлых расчётов внутри HTTP-запроса

- Статус: Accepted
- Дата: 2026-10-28
- Этап: 02 (решение из `docs/03`, очередь — Stage 18)

## Контекст

Обучение длится минуты и часы, падает по памяти, а браузер может закрыться. Внутри HTTP-запроса это теряет работу и блокирует API.

## Решение

API только валидирует запрос и создаёт idempotent job. Обучение, инференс моделей, загрузка данных и большие симуляции выполняет `services/worker`. Браузер следит за статусом через polling или SSE.

## Как проверяется

Контракт import-linter «API never trains, forecasts or ingests inside an HTTP request» запрещает `multiverse_api` импортировать `multiverse_forecast`, `multiverse_causal` и `multiverse_pipelines`. Проверка входит в `npm run check` и CI.

## Последствия

Даже простые расчёты для API, если они растут в стоимости, переезжают в worker. Демо-расчёт V1 выполняется в браузере (Web Worker) и помечен DEMO.

## Отвергнутые альтернативы

Background tasks внутри процесса API: теряются при рестарте, не имеют checkpoint и бюджета.
