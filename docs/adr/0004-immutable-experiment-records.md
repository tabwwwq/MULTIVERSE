# ADR-0004 — Неизменяемые записи экспериментов и результатов

- Статус: Accepted
- Дата: 2026-10-28
- Этап: 02 (решение из `docs/03`)

## Контекст

Если результат можно тихо перезаписать, отчёт перестаёт быть доказательством (PRD FR-RP-03, FR-LB-02).

## Решение

Contracts неизменяемы (`frozen=True`). Изменение сценария создаёт новую revision. Каждый результат идёт с `ReproducibilityManifest`: scenario ID, revision, режим, происхождение данных, cutoff, seed, версия кода, dataset snapshot, model ID, версия contracts. Исправленные данные — новый snapshot, а не правка старого.

## Как проверяется

Тест `test_contracts_are_immutable`. Валидатор manifest требует dataset snapshot и model ID для эмпирических режимов.

## Последствия

Хранилища (local storage в V1, PostgreSQL и object storage позже) только добавляют записи. Удаление — отдельная операция владельца, с аудитом.

## Отвергнутые альтернативы

Мутабельные записи с полем `updated_at`: история теряется, повтор результата невозможен.
