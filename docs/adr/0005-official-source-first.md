# ADR-0005 — Сначала официальные источники

- Статус: Accepted
- Дата: 2026-10-28
- Этап: 02 (решение из `docs/03` и `docs/04`, реализация — Stage 09–13)

## Контекст

Неофициальные агрегаторы данных меняют значения без истории, а их лицензии запрещают распространение (PRD PR-07).

## Решение

Приоритет: SEC EDGAR → FRED / ALFRED → ECB SDMX → World Bank → investor relations (если reuse легален) → лицензированные данные (только после письменных terms). Сетевые загрузки выключены по умолчанию (`MULTIVERSE_ALLOW_NETWORK_DOWNLOADS=false`). Для SEC обязателен User-Agent с контактным email и консервативный throttle.

## Как проверяется

`Settings` отклоняет включённые загрузки без `MULTIVERSE_SEC_USER_AGENT` и User-Agent без email (тесты `packages/config/tests`). Raw-данные живут в `var/`, который игнорируется git.

## Последствия

Любой новый источник сначала попадает в source catalog (Stage 09) с лицензией и rate limits, и только потом в код.

## Отвергнутые альтернативы

Сторонние API с «удобными» данными: нет provenance и права на распространение.
