# ADR-0028 — Причинная часть: исследование выполнимости вслепую, оценка эффекта закрыта аудитом

- Статус: Accepted
- Дата: 2026-11-06
- Этап: 20

## Контекст

Промпт 20 требует отдельный исследовательский модуль: DAG, estimand и identification assumptions для каждого решения, оценку выполнимости matched cohort, weighted regression, DiD и event study, synthetic control, чувствительность к скрытому смешению, плацебо-даты, pre-trends, negative controls, пересечения событий и гетерогенность секторов. Приёмка допускает явное исследование невыполнимости.

Аудит Stage 19 блокирует причинную работу: 48 событий, один рецензент ИИ, ни один тип не набрал 30 событий. Владелец: «Stage 20 без выводов».

Если заглянуть в результаты после событий сейчас, анализ будущей версии уже не будет чистым: выбор метода будет знать ответ.

## Решение

1. **Исследование выполнимости, а не оценка.** Контракт `CausalStudy` не имеет поля для эффекта: `effects_estimated` может быть только 0, `outcomes_after_treatment_read` только `false`, метка только `feasibility_study_no_effect_estimated`.
2. **Слепота.** Диагностика не читает результат обработанной фирмы с квартала события. Обработанная фирма выбывает из контрольных навсегда, начиная за 8 кварталов до события. Тест заменяет все значения после события на мусор: ни одна цифра не меняется.
3. **Ворота.** `difference_in_differences` проверяет `credible_for_causal_work` аудита и иначе бросает `CausalWorkBlockedError`. Оценка проверена только на придуманной панели с известным эффектом. На настоящих событиях она не запускалась.
4. **Граф — гипотеза.** Узлы макро, состояние фирмы, ожидания менеджмента (не наблюдаются), решение, другие решения, издержки, спрос (не наблюдается), результат. Каждое ребро с обоснованием, упущенное перечислено.
5. **Что измеряется:**
   - support: доля обработанных внутри диапазона propensity контрольных;
   - balance: стандартизованная разность до и после сопоставления;
   - pre-trends: лиды −8..−2 против контрольной пары;
   - плацебо-даты: за 6, 8 и 10 кварталов до события;
   - negative control: псевдо-события на фирмах без действия, 500 выборок; отсюда частота ложных срабатываний и минимальный обнаружимый эффект;
   - E-value для этого минимума;
   - synthetic control: подгонка и проверка на периоде до события;
   - пересечения и распределение по секторам.
6. **Контрольные** — фирмы того же дивизиона SIC без 8-K этого типа в ±8 кварталов. Ближайшая по ковариатам на квартал до события. Размер, рост и маржа обязательны, остальные по мере наличия. Ковариат после события нет.
7. **Правила выполнимости записаны до запуска** (`RULES`) и применяются автоматически.
8. **Окно** считается от момента приёма первого документа события.

## Последствия

- Будущая оценка останется чистой: выбор метода не зависит от результата.
- Минимальный обнаружимый эффект показывает, сколько событий нужно, ещё до их чтения.
- Причинных чисел в проекте нет. Экран `/causal-map` говорит об этом первым.
