## Сбор и очистка

- **Отбор:** 1000 компаний по письменным правилам и seed, стратификация по дивизионам SIC. Компании, снятые с регистрации, остаются.
- **Нормализация:** значения XBRL в канонические квартальные показатели с полной родословной до файла.
- **Point-in-time:** факт доступен с момента публикации, а не с конца периода. Витрина отвечает, что было публично на любую дату.
- **Неизменяемость:** архив `var/raw` с SHA-256, сборки названы хэшем.

## Пропуски

- **Пропуск не равен нулю.** Он остаётся `null` с маской.
- Худшая основная метрика — CAPEX: 28,8% пропусков там, где отчёт был публичен. Выручка: 17,7%.
- У 257 компаний есть кварталы без выручки внутри истории.
- Октябрь 2025 по UNRATE и CPI помечен в источнике как пропуск.

## Survivorship

Выборка взята из всех 7 573 подходящих компаний, а не из живых. 653 отчитываются, 347 сняты с регистрации. Смягчает смещение, но не снимает его: компаний, исчезнувших в первые годы XBRL, нет. Банкротства отражены частично: 191 документ 8-K item 1.03, 343 снятия с регистрации.

## Риск утечки из будущего

Контроль есть на каждом шаге: момент публикации, метки первого выпуска, лаг признаков, проверка Gate B с доказательством отсутствия утечки. Остаточный риск: текущие SIC и тикеры не протянуты назад, поэтому исторические отраслевые метки не точны.

## Персональные данные

- Финансовые факты компаний обычно не персональные данные.
- В `var/raw` есть полные документы SEC: подписи и имена руководителей. Наружу не передаются.
- Публичный реестр событий просканирован: 283 фрагмента, ни одного обращения, адреса или телефона. Один найденный личный по форме оборот — название дилерской группы. Проверка эвристическая.
- Подробно: [инвентаризация данных](../security/gdpr-data-inventory.md).

## Известные предупреждения Gate B

Смена понятий между годами: 2 004 случая, 8 018 значений с флагом. Выбросы и скачки оставлены с пометкой: кризисы настоящие. Полный список из 14 предупреждений в `var/data/gate`, сводка в [отчёте 14b](../stages/14b-data-acquisition.md).

## Для чего подходит

Исследование динамики нефинансовых компаний США по отчётности. Не подходит для оценки эффектов решений, для цен акций и для компаний вне вселенной.

## Как пересобрать

Код в git, правила в манифесте вселенной, сырьё — из официальных источников, кроме FRED, пока открыт блок.
