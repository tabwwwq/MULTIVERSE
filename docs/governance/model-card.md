# Model card — временная прогнозная модель

| Поле | Значение |
|---|---|
| Модель | `model-20261028-9ce4d4180aa9`, GRU с attention, без калибровки |
| Статус | **Подписана для исследования на 3 из 15 пар. Не одобрена для продукта. Обучение на FRED под открытым лицензионным блоком** |
| Владелец | Владелец проекта. Он один и разработчик, и утверждающий: независимой проверки нет |
| Подробные отчёты | [Stage 16](../stages/16-model-card.md), [Stage 17](../stages/17-probabilistic-validation.md), [пакет оценки](../stages/17-evaluation-package.md) |
| Версия карты | 2026-11-06, Stage 24 |

> **Лицензионный блок LIC-001.** Условия FRED запрещают обучение на контенте FRED, а модель обучена с 7 признаками из него. Новое обучение на этих признаках отказывает. Веса не публиковать. Без решения владельца модель не показывать как готовый результат. Подробно: [реестр лицензий](../security/license-inventory.md).

## Назначение

Прогноз динамики компании **без вмешательств**: рост выручки, операционная, EBITDA и FCF маржа, debt/EBITDA. Только исследование.

**Подписанные пары:** операционная маржа h = 8, EBITDA маржа h = 4 и h = 8. Остальные 12 пар правило не прошли.

## Запрещённое использование

- Оценка эффекта решения. Точность прогноза ничего не говорит об эффекте вмешательства.
- Инвестиционные решения и советы.
- Трактовка интервалов как гарантии покрытия вне измеренного периода.
- Компании вне вселенной: финансовый сектор, иностранные эмитенты, компании без 10-K и 10-Q с XBRL.
- Показ числа как рыночной оценки.

## Распределения целей и проверка

- **Страна:** только США.
- **Сектора:** дивизионы SIC вселенной, срезы есть в пакете Stage 17. На редких секторах десятки строк, покрытие шумное.
- **Период выбора:** development 2020–2023. **Период вердикта:** final 2024–2026.
- **Протокол** закреплён файлом до первой оценки. Выбранные настройки не менялись.

## Измеренное качество

| Мера | Результат |
|---|---|
| Разрыв покрытия с номиналом | Около 2–4 п. п. на знакомых фирмах |
| Покрытие в 2020 | Заметно хуже: шок года |
| Рост выручки h = 4, final | Покрытие 50/80/90: 55,2 / 83,3 / 93,2 |
| К persistence, рост h = 4 | Pinball −41,8% (−46,3..−36,4) |
| К `gbm_quantile` | В целом сеть не лучше: разница около 1%, по парам разная |
| Калибровка | Не помогла на development, в модель не вошла |
| Запоминание фирм | Признаков нет |

Значимость: интервалы — bootstrap по фирмам. Числа относятся к этой вселенной и этому срезу.

## Известные слабости

- **Final не полностью нетронут:** годы 2024–2026 входили в сводные таблицы Stage 15–16. Настоящая проверка — отчёты новее 2026-10-28.
- Горизонты h = 12 и 20 без вердикта: метки ещё не опубликованы.
- Debt/EBITDA на коротких горизонтах часто хуже persistence.
- Рост у незнакомых фирм на h = 8 и 12 прогнозируется хуже.
- Survivorship смягчён, но не снят, см. data card.
- Макро-признаки не дают измеримого выигрыша: ablation +0,1% по pinball.

## Дрейф, переобучение, откат

| Пункт | Как сейчас |
|---|---|
| Мониторинг дрейфа | Нет: модель не работает в продукте. OOD-правило |z| > 4 только на оценке |
| Триггер переобучения | Новый срез данных или решение по LIC-001 |

| Откат | Веса и манифесты хранятся по неизменяемым ID в `var/`, в git только отчёты |

## Безопасность артефактов

Чекпоинты содержат только тензоры и текст, загрузка идёт с `weights_only=True`. Перед чтением проверяется SHA-256. Веса в репозиторий не входят, это проверяет `tests/smoke/test_packaging.py`.
