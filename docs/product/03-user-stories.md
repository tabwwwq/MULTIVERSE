## User stories

### US-01 — Поиск компании по старому тикеру
**Persona:** P2 · **P0** · **V1** (fixtures), V2 · **FR:** FR-CO-01, FR-CO-02

*Как* аналитик, *хочу* найти компанию по тикеру, который она использовала раньше, *чтобы* изучать её историю до переименования.

- Дано fixture-компания со сменой тикера, когда ввожу старый тикер, тогда вижу компанию с пометкой «alias до YYYY-MM-DD».
- Stable company ID одинаков для старого и нового тикера.

### US-02 — Только то, что было известно на дату
**Persona:** P2, P4 · **P0** · **V1** fixtures, V2 · **FR:** FR-TM-01, FR-TM-02

*Как* исследователь, *хочу* видеть, когда историческое значение стало публичным, *чтобы* быть уверенным, что анализ на дату *t* не использует будущее.

- Дано значение за 2020Q4, поданное в феврале 2021, когда выбираю as-of 2020-12-31, тогда значения нет в dossier, а coverage это отражает.
- Tooltip каждого значения показывает `filed_at`.

### US-03 — Однозначная величина R&D
**Persona:** P4, P1 · **P0** · **V1** · **FR:** FR-DE-01, FR-DE-02

*Как* студент, *хочу* задать R&D +40% с явной единицей, *чтобы* не путать «+40% к бюджету» и «+40 p.p. от выручки».

- Дано форма R&D, когда ввожу 40, тогда обязан выбрать unit (`fraction_of_previous_rnd_budget` или `pp_of_revenue`), иначе Validate показывает ошибку.
- В отчёте величина выводится с полной единицей.

### US-04 — Financing mix сделки
**Persona:** P1 · **P0** · **V1** · **FR:** FR-DE-04

*Как* консультант, *хочу* задать доли cash / debt / equity для покупки, *чтобы* видеть влияние финансирования на leverage и dilution.

- Дано доли 60 / 30 / 5, когда нажимаю Validate, тогда вижу ошибку «доли дают 95%, нужно 100%» и Run недоступен.
- При 60 / 40 / 0 валидация проходит.

### US-05 — Предупреждения до запуска
**Persona:** P3 · **P0** · **V1** · **FR:** FR-DE-05, FR-DE-06, FR-DE-07

*Как* CFO, *хочу* видеть предупреждения (OOD, мало истории, нет калибровки) до запуска, *чтобы* понимать надёжность результата заранее.

- Дано величина действия вне исторического диапазона, когда нажимаю Validate, тогда вижу warning `out of distribution` и объяснение последствий.
- Blocking errors выключают Run, warnings — нет.

### US-06 — Закрыть браузер и не потерять задачу
**Persona:** P4 · **P0** · **V2** · **FR:** FR-SI-01, FR-SI-02, FR-SI-03

*Как* исследователь, *хочу* закрыть вкладку во время долгого расчёта, *чтобы* вернуться позже и увидеть результат.

- Дано job в состоянии RUNNING, когда закрываю и снова открываю приложение, тогда вижу тот же job ID, статус и last heartbeat.
- Повторное нажатие Run с тем же Idempotency-Key не создаёт второй job.

### US-07 — Отмена без потери checkpoint
**Persona:** P4 · **P0** · **V2** · **FR:** FR-SI-04

*Как* пользователь, *хочу* остановить дорогой эксперимент, не теряя последний checkpoint, *чтобы* продолжить позже.

- Дано обучение в RUNNING, когда нажимаю «Stop after checkpoint», тогда job переходит в STOPPED и показывает путь checkpoint и кнопку Resume.
- Force kill показывает предупреждение о потере текущей эпохи.

### US-08 — Честное сравнение с фиксированным seed
**Persona:** P4 · **P0** · **V1** · **FR:** FR-SI-06, FR-SI-07, FR-RE-06

*Как* студент, *хочу* сравнить R&D +20% и +40% для одной фирмы при одном seed, *чтобы* разница зависела только от параметра.

- Дано два сценария с одинаковыми seed, as-of и horizon, когда открываю Compare, тогда вижу paired delta distribution.
- Повторный запуск обоих сценариев даёт идентичные числа.

### US-09 — Смысл полосы неопределённости
**Persona:** P1 · **P0** · **V1** · **FR:** FR-RE-01, FR-RE-04, FR-RE-05

*Как* консультант, *хочу* понимать, что означает полоса p10–p90, *чтобы* не пообещать клиенту лишнего.

- Дано результат, когда навожу на полосу, тогда вижу «conditional model quantiles» и статус калибровки (`not validated` в V1).
- Панель «Что это НЕ значит» видна без прокрутки на desktop.

### US-10 — EV и equity value не путаются
**Persona:** P2 · **P0** · **V3** · **FR:** FR-VA-01, FR-VA-02

*Как* аналитик, *хочу*, чтобы EV и equity value никогда не назывались одним словом, *чтобы* оценка была корректной.

- Дано результат DCF, когда открываю Valuation Studio, тогда вижу отдельные строки «Enterprise value (DCF, model)» и «Equity value (model)» и bridge между ними.
- При WACC ≤ g расчёт отклоняется с объяснением.

### US-11 — Доказать коллеге, откуда допущения
**Persona:** P1, P3 · **P0** · **V1** · **FR:** FR-LB-01, FR-LB-02, FR-DE-07

*Как* консультант, *хочу* сохранить набор допущений с источниками defaults, *чтобы* доказать коллеге, откуда они взяты.

- Дано сохранённый сценарий, когда открываю Assumption Matrix, тогда у каждого параметра видно значение, диапазон и источник default.
- После экспорта отчёта правка создаёт новую revision, а старая не меняется.

### US-12 — Reproducibility manifest
**Persona:** P4 · **P0** · **V1** demo, V4 · **FR:** FR-RP-01, FR-RP-02, FR-RP-03

*Как* ревьюер, *хочу* скачать reproducibility manifest и методологические ограничения, *чтобы* повторить результат.

- Дано результат, когда экспортирую отчёт, тогда manifest содержит scenario ID, revision, dataset snapshot, model ID, seed, code version, as-of и источники.
- Повторный экспорт той же revision даёт тот же manifest.

### US-13 — Таблица вместо графика
**Persona:** все · **P0** · **V1** · **FR:** FR-RE-03, NFR-A11Y-01

*Как* пользователь screen reader, *хочу* получить данные графика таблицей, *чтобы* работать без визуального графика.

- Дано любой график, когда переключаюсь на «Table», тогда вижу те же значения с единицами и могу скачать CSV.
- График имеет текстовое summary для screen reader.

### US-14 — Demo отличим от эмпирики
**Persona:** Visitor, P1 · **P0** · **V1** · **FR:** FR-RE-04, SYN-01…SYN-08

*Как* посетитель, *хочу* сразу видеть, что сценарий построен на синтетике, *чтобы* не принять его за реальные данные компании.

- Дано demo-сценарий, когда открываю любой экран результата, тогда вижу бейдж DEMO, водяной знак SYNTHETIC и вымышленное название компании.
- Экспорт demo содержит суффикс `_DEMO` и предупреждение в первой строке.

### US-15 — Утверждение модели администратором
**Persona:** Admin · **P1** · **V2** · **FR:** FR-AD-01, FR-MO-02

*Как* владелец проекта, *хочу* утверждать версию модели, *чтобы* пользователи не запускали непроверенные модели.

- Дано модель без approval, когда пользователь открывает Launch Center, тогда она недоступна для выбора.
- В Model Observatory видны метрики только из реальных runs, с dataset hash и config.

## Failure cases

| ID | Ситуация | Ожидаемое поведение | Сообщение пользователю | Чего нельзя допустить | Тест |
|---|---|---|---|---|---|
| FC-01 | Компания не поддерживается (IFRS / foreign filer, нет XBRL) | Состояние «Unsupported» с причиной, ссылка на Data Catalog | «Компания отчитывается по IFRS (20-F). V1–V2 поддерживает только US-GAAP» | Пустой dossier без объяснения или подстановка данных другой компании | E2E на fixture IFRS-компании |
| FC-02 | Мало истории (< 8 валидных кварталов на as-of) | Разрешён только DEMO. Empirical и causal заблокированы | «Недостаточно истории: 5 из 8 нужных кварталов. Доступен только demo-режим» | Модельный прогноз на дырявой истории без флага | Fixture с 5 кварталами |
| FC-03 | As-of раньше первых данных | Блокировка шага 2 с ближайшей допустимой датой | «Первые данные компании опубликованы 2011-03-01» | Пустые графики как «нулевые» значения | Unit + E2E |
| FC-04 | Попытка обойти PIT через URL или API (as-of в будущем относительно данных или подмена параметра) | API отклоняет запрос (400) с причиной | «Дата cutoff позже последнего snapshot» / «lookahead cutoff rejected» | Ответ с данными, поданными после cutoff | Contract test с подменой параметра |
| FC-05 | Financing mix ≠ 100% или неоднозначная unit | Validate показывает ошибку у конкретного поля, Run выключен | «Доли финансирования дают 95%. Нужно ровно 100%» | Автоматическая нормализация без согласия | Property test |
| FC-06 | Экстремальная величина действия (R&D +500%) | Warning `out of distribution`; выше жёсткого лимита — отказ | «Значение вне исторического диапазона (max 120%). Результат будет фиктивным» | Уверенный узкий интервал для OOD | Boundary tests |
| FC-07 | Модель недоступна | Результат не строится. Предложение demo-fallback только с согласия | «Модель v0.3 недоступна. Показать demo-расчёт с меткой DEMO?» | Тихая подмена синтетикой | Integration test |
| FC-08 | Worker упал во время расчёта | Job → FAILED с incident ID, idempotent retry | «Расчёт прерван (incident ID …). Повторить?» | Потерянный job, дубль результата, логи с секретами | Forced worker failure test |
| FC-09 | Сравнение несовместимых сценариев (разные currency, horizon или as-of) | Compare блокируется, предлагается метод выравнивания | «Сценарии имеют разный as-of (2021-12-31 и 2022-12-31). Сравнение недоступно» | Сравнение графиков на одной оси без пометки | Negative E2E |
| FC-10 | Ошибка local storage (quota, private mode) | Сообщение и предложение экспортировать JSON | «Хранилище браузера недоступно. Скачайте сценарий файлом, чтобы не потерять его» | Тихая потеря сохранения | E2E с эмуляцией quota |
