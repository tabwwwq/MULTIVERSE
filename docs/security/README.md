## Как работать с API

Локально ничего настраивать не нужно: `npm run dev:api` слушает `127.0.0.1` в режиме `local`.

Выпустить токен для режима `token`:

```bash
uv run python -m multiverse_api.tokens --name alice --role operator --days 30
```

Токен показывается один раз. В `MULTIVERSE_API_PRINCIPALS` идёт только напечатанная запись с хэшем.

| Настройка | По умолчанию | Что ограничивает |
|---|---|---|
| `MULTIVERSE_AUTH_MODE` | `local` | Режим входа |
| `MULTIVERSE_CLOUD_SPEND_LIMIT_USD` | 0 | Все платные задания вместе |
| `MULTIVERSE_MAX_ACTIVE_JOBS` | 8 | Незавершённые задания одного владельца |
| `MULTIVERSE_DAILY_COMPUTE_SECONDS` | 43 200 | Запрошенные секунды владельца за 24 часа |
| `MULTIVERSE_RATE_READS_PER_MINUTE` | 300 | Чтения принципала |
| `MULTIVERSE_RATE_WRITES_PER_MINUTE` | 30 | Записи принципала |
| `MULTIVERSE_RATE_FAILURES_PER_MINUTE` | 10 | Неверные токены с одного адреса |
| `MULTIVERSE_MAX_BODY_BYTES` | 262 144 | Размер тела запроса |
| `MULTIVERSE_AUDIT_RETENTION_DAYS` | 90 | Срок журнала аудита |

## Лимиты вычислений

Все проверки стоят в очереди, поэтому их не обойти ни через API, ни через CLI.

| Ступень | Проверка |
|---|---|
| Подача | Платное задание при лимите 0 отказывает. Сумма зарезервированных лимитов не выше общего. Оценка не выше лимита задания. Лимит активных заданий и секунд за сутки |
| Одобрение | Только `admin`. Расходы проверяются заново: лимит могли снизить |
| Взятие воркером | Расходы проверяются ещё раз. Задание сверх лимита останавливается, не начавшись |
| Выполнение | На каждой безопасной точке сверяются бюджет времени и расходов задания |
