## Вывод

Сейчас сервер почти ничего личного не держит. Личное лежит в браузере пользователя и в истории git. Корпоративные финансовые факты обычно не персональные данные, но ссылки на события и логи могут ими быть, поэтому они проверены отдельно.

## Проверка корпоративных текстов

Просканированы все свободные тексты `data/events/registry.json` и `sample.json`: 283 фрагмента.

| Проверка | Результат |
|---|---|
| Обращения Mr., Ms., Mrs., Dr. | 0 |
| Адреса email | 0 |
| Телефоны | 0 (совпадения — номера документов и CIK) |
| Пары слов, похожие на имя | 17, из них 16 — названия компаний и продуктов, 1 — «Jim Koons», название дилерской группы в описании сделки |
| Упоминания должностей | 1, без имени |

Это эвристика, а не гарантия. Правила разметки требуют писать о решении компании, а не о людях.

Документы SEC в `var/raw` содержат подписи и имена руководителей. Они не публикуются и лежат только локально.

## Что изменится при публикации

1. Назвать контролёра и контактный адрес.
2. Опубликовать политику по [этому плану](privacy-policy-outline.md).
3. Настроить журналы прокси и их срок хранения.
4. Заключить договоры с хостингом.
5. Повторить эту инвентаризацию.
