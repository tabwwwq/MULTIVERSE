## 1. Scope

Подключение FRED/ALFRED, ECB и World Bank по docs/04 с их требованиями и лицензиями: реестр серий, момент доступности каждого значения, хранилище vintages, as-of join с финансовыми кварталами, QA моментов публикации, joined panel с provenance. Обучения нет.

**Реальные макроданные не загружены.** Ключа FRED в `.env` нет: его регистрирует владелец, решение D-11. Загрузки ECB и World Bank ждут решения D-12. Вопрос о решениях был задан в начале этапа, ответа не было, и владелец написал «дальше». Поэтому весь путь построен и проверен на синтетических документах той же формы, что настоящие ответы API. Реальные данные пойдут через те же функции одной командой `fetch` после решений.

## 3. Отчёт этапа

### Done

- **Metadata catalog** (`macro/registry.py`, contract `MacroSeries`, contracts 0.10.0). Начальные индикаторы промпта:
  - Fed policy rate — `FEDFUNDS`, среднее за квартал;
  - инфляция — `CPIAUCSL`, год к году последнего месяца;
  - безработица — `UNRATE`, среднее;
  - рост GDP — `GDPC1`, год к году;
  - кривая доходности — `DGS10` и `T10Y2Y`, конец квартала;
  - индикатор рецессии — `USREC`, максимум за квартал;
  - ECB: курс EUR/USD, ставка по депозитам, доходность 10-летних AAA-облигаций еврозоны (конец квартала);
  - World Bank: рост GDP, инфляция, безработица, GDP на душу для США и еврозоны (последний доступный год).
- **Описано для каждой серии** (реестр и `qa.md`):
  - geographic alignment: компании sample — внутренние эмитенты США, поэтому серии США основные, серии еврозоны — внешний контекст;
  - частота, единица и unit conversion: проценты остаются процентами, индекс CPI переводится в рост год к году, уровень GDP — в рост год к году;
  - сезонная корректировка;
  - часовой пояс публикации;
  - рабочие дни: дневные ряды — только рабочие дни, конец квартала берётся из последних 10 дней;
  - лаг публикации и частота пересмотров.
- **Момент доступности** (`macro/availability.py`):
  - ALFRED — конец дня vintage по US Eastern;
  - World Bank — конец дня `lastupdated` датированного snapshot;
  - ECB — правило публикации: курс 16:00 CET; кривая 12:00 CET следующего дня TARGET, праздники TARGET вместе с Пасхой посчитаны в коде; ключевая ставка — с начала дня, с которого действует.

  Правила летнего времени ЕС и США написаны в коде (на Windows нет базы часовых поясов).
- **Парсеры** (`macro/parsers.py`):
  - ALFRED: строки с real-time периодом становятся интервалами; конец интервала — конец следующего дня после `realtime_end`; «.» — пропуск;
  - ECB `csvdata` по ключу серии;
  - World Bank: несколько датированных snapshots одного индикатора. Изменение значения открывает новый интервал, исчезновение закрывает. Значения сохраняются как опубликованы («100.0» остаётся «100.0»).
- **Хранилище vintages** (`macro/store.py`) — SQLite: `var/data/macro/macro.sqlite` для архива и отдельный `macro-synthetic.sqlite`.
- **As-of macro join с финансовыми кварталами** (`macro/join.py`, contract `MacroCell`):
  - окно — собственный фискальный квартал компании из PIT panel Stage 12, иначе календарный;
  - 6 transforms, все входы из одного vintage;
  - состояния: observed / not_yet_released / unavailable / not_covered / unusable;
  - у значения есть входные observations с моментом доступности, основанием и SHA-256 raw-файла;
  - `check_macro_point_in_time` отказывает join со входом позже cutoff;
  - причина пустой ячейки строится только из правил серии, без дат будущих публикаций.
- **Загрузки** (`macro/fetch.py`, команда `fetch`):
  - замки: сеть на одну команду, решение владельца, ключ FRED;
  - ключ отправляется только в запросе, в индексе архива и сообщениях — `api_key=REDACTED`;
  - серия FRED с «copyright» в notes пропускается (условия FRED для сторонних серий);
  - FRED запрашивается с полным real-time диапазоном;
  - бюджет 20 MB на источник, 1 запрос в секунду.
- **Graceful degradation.** Без ключа и решений:
  - `status` показывает, чего нет (ключ — только «set / not set»);
  - `build` сообщает о пустых источниках и завершается кодом 0;
  - `join` даёт `unavailable` с причиной в каждой ячейке («MULTIVERSE_FRED_API_KEY is not set: the owner registers the FRED key (D-11)»);
  - `fetch` отказывает до первого запроса.
- **Синтетика** (`macro/synthetic.py`). Документы формы ALFRED, ECB и World Bank с реалистичными паттернами публикаций:
  - релизы после месяца;
  - три оценки GDP и сентябрьский пересмотр;
  - сезонные пересмотры CPI и безработицы;
  - рецессия, помеченная задним числом при объявлении;
  - рабочие дни и праздники TARGET;
  - годовые обновления базы World Bank с пересмотрами.

  Значения синтетические, помечены в каждой observation и ячейке, хранятся отдельно.
- **QA моментов публикации** (`macro/qa.py`, команда `qa`): `series.json` (metadata catalog), `qa.json`, `qa.md` с покрытием, vintages, лагом (min / median / max), пересмотренными периодами и проблемами.
- **Joined panel с provenance** (`macro/joined.py`): `joined.csv` (финансовые и макро-строки), `macro_cells.jsonl`, `manifest.json`. Id = SHA-256 snapshot PIT и макроячеек.
- `RawObject` принимает формат `csv` (ECB).

### Known limitations

- **Реальных макроданных нет** до решений D-11 (ключ FRED) и D-12 (ECB, World Bank). Числа выше — механика на синтетике.
- **Час релиза FRED не известен:** значение считается доступным с конца дня vintage. Признак может появиться на часы позже реального релиза (обычно 8:30 ET), но никогда раньше.
- **У ECB нет истории публикаций.** Используются только ряды, которые не пересматриваются; время — по правилу публикации. Ряд ECB с пересмотрами потребует собственных датированных snapshots.
- **World Bank без архивных версий** даёт `unusable` для cutoff раньше первого snapshot. Исторические версии — архив WDI (source 57), входит в D-12.
- **Праздники США для дневных рядов FRED** не моделируются отдельно: момент берётся из ALFRED, а конец квартала — из последних 10 дней.
- **Geographic alignment упрощён:** все 10 компаний sample — внутренние эмитенты США, поэтому каждая получает все 18 признаков (США как основные, еврозона как контекст). Выручка по странам потребует сегментных данных (не в Company Facts).
- **Transform выбран один на серию.** Другие (q/q annualized, разница) — новая запись реестра с тестом.

### Decisions

- Признак допустим по моменту доступности; подпись периода не используется ни для чего, кроме окна (ADR-0020).
- Основания доступности: vintage, snapshot, schedule. `estimated` никогда не становится признаком.
- Join видит только прошлое, в том числе в причинах пустых ячеек.
- Окно признака — фискальный квартал компании; входы признака — из одного vintage.
- Синтетика той же формы, что источники, хранится отдельно и помечена в каждой ячейке.
- Без ключа и решений — мягкая деградация, а не падение.
