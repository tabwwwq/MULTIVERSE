## 1. Scope

Владелец прислал два снимка: диалог Run говорил, что движка нет, а Timeline Explorer показывал только демо. Задача этапа: реальные компании вместо вымышленных, их прогноз и работающий запуск.

**Что здесь не утверждается.** Рейтинг — это не рыночная капитализация. Прогноз — исследовательский: модель не одобрена для продукта, а её качество измерено только на прошлых годах. Результаты Run условны на допущения кейса, это не прогноз и не совет.

## 3. Отчёт этапа

### Done

- **Рейтинг (`pipelines/.../sec/top.py`).** Значение float берётся с обложки последнего 10-K. Свежесть считается по дате подачи 10-K, не больше 460 дней. По дате float считать нельзя: Broadcom, Disney и Deere подают отчёты не по календарному году и выпали бы. Ошибки масштаба ловятся сверкой с активами и с прошлым float, исправленные значения помечены. Фонды и SPAC исключены. Тикеры берутся из официального списка SEC: у Exxon Mobil в submissions тикеров нет.
- **Витрина на 1429 компаний.** Это топ-500 вместе с выборкой Stage 14b, чтобы модель видела и небольшие компании. Две находки по ходу. Банки подают тысячи таблиц комиссий по проспектам (`ffd`, у JPMorgan 4 260), и каждая заново пересчитывала всю историю. Они исключены, работа сократилась с 2,03 до 1,30 млрд шагов факт × точка, сборка заняла 23,5 минуты вместо часов. Ещё у одного эмитента нашёлся финансовый год 1989. Годы до 1990 в календарь не входят: XBRL начался в 2009.
- **Макро без FRED.** Ставки Treasury 3M и 10Y взяты напрямую у Treasury: работа федерального правительства, авторским правом не охраняется. Ставки ECB. У рядов World Bank нет датированных версий, поэтому point-in-time они видны только на последнем origin. В обучении их нет, на живой строке они обнуляются (`without_unseen`).
- **Nowcast-строка.** Последний origin — 2026-12-31, с тем, что известно на 2026-11-06. Без неё отчёты за октябрь не попали бы в прогноз.
- **Обучение.** Протокол Stage 16 без изменений: baselines, затем GRU с attention и TCN, 4 года валидации, 7 тестовых лет, 5 seeds. Валидация выбрала GRU: hidden 64, 1 слой, dropout 0.3. Живая подгонка использует ровно эти настройки.
- **Живой прогноз (`multiverse_forecast live`).** Одна подгонка на всех строках с известными целями, все фирмы, 10 seeds, прогноз — их среднее. Подгонку саму по себе оценить нельзя: её цели ещё не наступили. Её качество — то, что бенчмарк измерил на прошлых годах.
- **Экспорт (`multiverse_simulation companies`).** Пишет по файлу на компанию в `data/companies` (досье, доказательство ранга, прогноз, кейс или причина его отсутствия) и кейсы для воркера в `var/data/cases`.
- **Замены в кейсе.** Многие крупные эмитенты не дают частей EBITDA тегами: Exxon Mobil и Eli Lilly не подают операционную прибыль, Microsoft — квартальную амортизацию. Кейс берёт ближайший показатель, который эмитент подаёт: сначала EBITDA, затем операционную прибыль плюс D&A, затем денежный поток от операций. Центральный путь маржи строится из ближайшего прогноза модели. Если своих кварталов маржи у фирмы мало, шоки маржи берутся только секторные. Каждая замена записана во входах кейса как `assumed`, и диалог Run показывает её до запуска.
- **ВВП в шоках кейса** — от World Bank, как он известен в день кейса. Кейс считается на сегодня, и всё в нём сегодня уже опубликовано.
- **Экраны.** Universe показывает 500 компаний по рангу, затем 7 вымышленных с меткой. Dossier: досье из SEC, график и таблица прогноза p10, p50, p90 на 1, 4 и 8 кварталов, предупреждение о статусе модели, источники. Decision Builder знает кейс компании. Run: оценка, подача, одобрение нажатием, ход в процентах, переход на `/run?job=`. Без движка диалог говорит запустить `npm run app`. `/timeline` показывает запуски этого компьютера.
- **Universe постранично:** по 50 компаний. Все 507 карточек сразу весили 2,5 МБ, и на телефоне проверки не укладывались во время.
- **`npm run app`** поднимает API, воркер и сайт. Если сайт уже работает на 3000, запускаются только API и воркер.
- **Контракты 0.22.0:** `UniverseCompany` с рангом, `LiveForecast`, `RealCompany`, `RealIndex`, новые секторы. Источник `us-treasury` в каталоге, загрузка разрешена решением D-14.

### Known limitations

- **Рейтинг — не капитализация.** Float не учитывает акции инсайдеров и бывает старше года. Компаний без 10-K здесь нет.
- **Модель не одобрена для продукта.** Подпись Stage 17 относится к старой модели на FRED. По правилу Stage 17 новая модель проходит 2 пары из 15: рост выручки на 4 и 8 кварталов. Прогноз маржей на экране — вне одобренных пар, и одобрение остаётся решением владельца.
- **World Bank в признаках модели пуст.** Прогноз опирается на SEC, Treasury и ECB.
- **Кейсы — эскизы.** PP&E, оборотный капитал и проценты в них предполагаются. 88 кейсов стоят на замене EBITDA, и она показана.
- **Списки `/dossier` и `/decisions`** по-прежнему выводят все 507 компаний, около 0,9 МБ каждый.
- **Hubbell на `/launch` и `/valuation`** остаётся кейсом Stage 22, считанным с серий FRED. Блоки LIC-001, LIC-002, LIC-003 открыты.
- **Run и прогноз требуют своей машины.** Нужны `npm run app` и данные в `var/`. Опубликованный сайт без движка покажет прогноз, а Run ответит подсказкой.

### Decisions

- **D-14 (владелец в чате, 2026-11-06):** реальные компании, все возможные данные, долгое обучение. Treasury добавлен как источник по этому решению.
- Решения по умолчанию, объявленные владельцу: без ответа про FRED обучение шло без FRED, ничего не удалено. Рейтинг — по public float. Покрытие указано числами.
- D-01 (демо-компании первыми) заменено: реальные компании идут первыми.
