# multiverse-causal

Causal research tools: DAGs, estimands, identification assumptions, estimators and diagnostics (`docs/05`). **Status: feasibility study (Stage 20).** The diagnostics read no outcome after a treatment, and effect estimators refuse to run until the audit of the event registry says the sample is credible.

Rule: a result is never labelled causal without a stored diagnostics artifact (PRD FR-CA-02).
