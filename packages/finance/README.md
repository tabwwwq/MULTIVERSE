# multiverse-finance

Pure financial formulas: P&L, cash flow, debt, FCFF / FCFE, DCF and the EV → equity bridge (`docs/07`). **Status: skeleton.** Formulas arrive in Stage 21 (statement engine) and Stage 23 (valuation).

Rules: no I/O, no web or ML frameworks, `decimal.Decimal` for money, deterministic functions with identity and property tests.
